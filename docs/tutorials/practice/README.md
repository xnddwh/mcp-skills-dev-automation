# 练习项目：从直觉到能交付

这是 8 章教程的**配套练习**。教程讲「为什么」，这里只管「做」。每个练习都贴一个真实场景，做完有验收，别的不多说了。

## 学习主题与分级

主题就是这套教程的主线：把一个 AI Agent 从「会聊天」带成「能交付」。

| 级别 | 对应章节 | 你要练什么 | 要不要装东西 |
|---|---|---|---|
| [Lv1 建立直觉](./level-1-intuition.md) | 01、02 | 编造、上下文、任务描述 | 不用，网页对话就行 |
| [Lv2 动手搭](./level-2-hands-on.md) | 03、04、05 | 装 agent、建记忆层、跑真实任务、接 MCP | 要 |
| [Lv3 流程与质量](./level-3-quality.md) | 06、07、08 | 踩坑、固化 skill、搭评测集、审计轨迹 | 要 |

建议节奏：Lv1 一晚上，Lv2 一个周末，Lv3 两三个周末。**顺序别倒**——Lv3 的评测练习建立在 Lv2 真跑起来之上。

## 每个练习长什么样

统一六段，别嫌啰嗦，格式固定是为了好对照：

```
场景    这件事在真实世界里对应什么
目标    一句话，可验收
步骤    编号，照做就行
查一查  这个练习里的检索/核实任务（对应教程的「先查证再实现」）
验收    怎么算做完
注意    容易翻车的地方
```

「查一查」是刻意加的。原因在第 02 章说过：涉及外部事实必须先核实。**练搜索和练动手一样重要**，而且它有个额外好处——你核实的都是官方文档，顺手就把包名、配置位置这些最容易过时的东西校准了。

## 三条版权规矩（先读，后面每个练习不再重复）

1. **材料用你自己的。** 整理你自己的文件夹、写你自己的周报、建你自己的台账。需要公开文档时，用开源项目的 README 或明确允许转载的内容，并且只看不改、不二次分发。
2. **AI 改写不改变版权归属。** 把一篇受版权保护的文章丢给 AI 让它「换个说法」，产出的东西你依然没有分发权。练习里产出的文字，只进你自己的笔记和台账，不对外发布。
3. **引用他人成果用链接。** 看到别人的 skill、项目、文章，想记下来就记**链接和出处**，不把文件复制进自己的仓库——除非它的许可证明确允许，并且你保留了许可证和署名。这条在 [`SKILL-TAXONOMY.md`](../../SKILL-TAXONOMY.md) 的来源说明里已经踩过实例。

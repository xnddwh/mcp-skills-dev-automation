# Lv1 · 建立直觉

四个练习，不装任何东西，用现成的网页对话就能做。目标只有一个：**在动手搭之前，先亲眼见过模型的三种行为**——编造、失忆、看指令下菜。

---

## Lv1-1 位置实验

**场景**：你怀疑「放中间的要求容易被忽略」是玄学。验证它。

**目标**：亲眼看到上下文位置对回答质量的影响，并找到出处。

**步骤**

1. 找一份 3000 字以上的文档。用开源项目的 README 或你自己写的东西，**不要**用别人付费或明确禁止转载的内容。
2. 准备一个需要对照文档回答的问题，要求里带 3 个具体约束（比如「只列前 3 条、注明所在段落、不超过 50 字」）。
3. 把这段「问题 + 约束」分别拼在文档的**开头、中间、结尾**，各问一次。
4. 三次回答并排记录：3 个约束各满足了几条。
5. 换一份长度相近的文档，重复一遍，看结论是否复现。

**查一查**

搜「lost in the middle」的**原始论文**（不是转述它的博客）。核对两件事：论文的实验设置和结论，跟教程第 02 章说的对不对得上。记下论文标题和年份——以后引用要能落到出处。

**验收**

一张三行对照表（开头/中间/结尾 × 满足几条），加一句你自己的结论。

**注意**

两次实验结论不一致很正常，这正是要学的：现象受文档长度、问题类型影响，不是开关。别把一次实验当成定律。

## Lv1-2 让它编一次

**场景**：教程反复说「模型会一本正经地编造」。你需要亲眼看一次，并且学会从语气里识别它。

**目标**：采集一次真实的编造，并把它变成一条预防规则。

**步骤**

1. 问一个**你确定它不可能知道**的本地事实。比如「我们公司上季度的差旅报销总额是多少」。
2. 记下它的回答，特别注意**语气**——它是迟疑，还是同样自信。
3. 追问：「你确定吗？这个数字的来源是什么？」看它怎么办——是承认不知道，还是现场编一个来源。
4. 换一个**需要联网才能答**的版本再问一次，对比两次行为。

**查一查**

去你所用模型的官方文档，找关于「可能产生不准确输出」的原文（这类声明一般在 usage policy 或 disclaimers 里）。抄下原话和链接。

**验收**

一条错误台账记录，格式照仓库 `templates/mistakes-ledger.md`。重点填 `Detection signal`——下次你怎么在它开口前就起疑。

**注意**

这是全套练习里**性价比最高的一个**。第 02 章那些「它会编」的文字，在这一刻之前对你只是知识；之后才是直觉。

## Lv1-3 三件套对比

**场景**：教程 04 说任务描述质量决定结果。这话值多少，测一下就知道。

**目标**：量化「任务描述质量」对结果稳定性的影响，产出你自己的模板。

**步骤**

1. 选一个真实的小任务。例如：把一段你自己写的杂乱记录整理成待办清单。
2. 写三个版本的任务描述：
   - A：只有目标（「帮我整理成待办」）
   - B：目标 + 背景（加上「这是项目周会的记录、我下周要用」）
   - C：背景 + 目标 + 验收（再加上「输出最多 5 条、每条带责任人、没有责任人的归入待定、不要替我编名字」）
3. 三个版本**各跑两次**，共 6 次。
4. 记一张 6 行的结果表：哪次最符合预期、哪次跑偏、偏在哪。

**查一查**

找你所用模型的**官方提示词指南**，看「提供上下文」「明确输出格式」这两条它原文怎么写的。对一下你 6 次实验的结论和官方说法是否一致。

**验收**

结果表 + 一份你自己写、自己验证过的三件套模板。这份模板直接存进你的备忘录，Lv2 会一直用。

**注意**

务必每个版本跑**两次**。跑一次你分不清「版本好」还是「这次运气好」——模型的输出是概率性的，单次结果说明不了问题。

## Lv1-4 核实一条传闻

**场景**：你在群里或文章里看到一个 AI 相关的说法。这条练习就是把教程里「先查证再实现」那条硬规则变成肌肉记忆。

**目标**：完成一次完整的一手来源核实。

**步骤**

1. 挑一条你最近看到的 AI 说法（某个模型的能力、某个工具是否免费、某项功能是否已发布）。把**原话和出处**记下来。
2. 只找一手来源：官方文档、官方博客、官方仓库、论文。**二手转述一律不算数**——包括教程本身，包括这本教程。
3. 写下四行：原说法 / 核实结果 / 来源链接 + 访问日期 / 还有什么没查到。

**查一查**

这条练习本身全都是「查一查」。额外要求一个动作：找到的来源如果是**别人转述官方**的，顺藤摸到官方原文为止。

**验收**

一条带来源、带日期的结论，并且**明确标出哪些没核实到**。没查到就说没查到，这比补一个猜测有价值得多。

**注意**

故意挑一条**你原本深信不疑**的说法来核。核实的结果无论证实还是证伪，你都会记住这次——这比核十条你本来就怀疑的说法有用。

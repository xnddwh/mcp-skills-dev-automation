# Lv2 · 动手搭

四个练习，都要装东西、真跑起来。对应教程 03、04、05 章。做完这级，你手里会有一个带记忆层的 agent 和一次真实任务记录。

---

## Lv2-1 最小 agent 上线

**场景**：教程 04 那套流程，你亲手走一遍。

**目标**：15 分钟内让一个属于你的 agent 跑通第一个任务。

**步骤**

1. 照教程 04 跑 `setup_my_agent.py`，生成三个起步文件。
2. 把 `skills/my-first-agent/` 复制到你的 skills 目录。
3. **重启客户端**。
4. 触发任务 1，然后做教程里那 🔬 三件事：文件真生成了吗、它认得到 skill 吗、抽查它解释的代码。

**查一查**

别信教程里写的落点路径——去你所用工具的**官方文档**确认 skills 目录的准确位置。教程可能过期，官方文档才是真源。顺手记下你工具的版本号。

**验收**

教程 04 的三件事全过，并且你能在客户端里看到它真的读了 `AGENT.md`。

**注意**

装完没反应，九成是没重启。剩下一成是目录名和 `name` 字段不一致。先查这两个，再去找别的。

## Lv2-2 记忆层初始化

**场景**：教程 05 的记忆系统，光看格式没用，得填过一次真的才知道难在哪。

**目标**：给一个你真实在用的项目建好 `AGENT.md` + `mistakes-ledger.md`，并验证 agent 会读。

**步骤**

1. 选一个你正在做的项目（没有就用你打算学的东西）。
2. 建两个文件：`AGENT.md` 写目标、常用命令、规矩；`mistakes-ledger.md` 先放模板。
3. **至少填一条真实内容**——比如今天你踩过的一个小坑。没有就先别写，空着比编造强。
4. 开新会话，只说「读 AGENT.md 和 mistakes-ledger.md」，然后问它：「你读到了哪些规矩？」

**查一查**

`CLAUDE.md`、`AGENTS.md`、`AGENT.md` 三个名字各工具认哪个——去各自官方文档确认，别靠猜。确认完把结论写进你的 `AGENT.md` 顶部，免得下次再查。

**验收**

开一个全新会话，它能准确复述你写的规矩，并且能说出台账里有几条记录。

**注意**

台账**宁可空着也不要编**。第 05 章那条「AI 可起草不可编造」对你同样适用——你现在就是在给它打样。

## Lv2-3 只读整理任务

**场景**：第一个真任务。选它是因为：材料现成、做错没损失、结果立刻可见。

**目标**：用三件套完成一次真实文件整理，并且验收过。

**步骤**

1. **先复制一份**你的下载文件夹（或任何要整理的目录），所有操作在副本里做。
2. 按三件套下任务，验收里必须包含三条硬约束：生成清单、拿不准的单独列出来问你、**不删除不重命名任何文件**。
3. 它说做完后，做三步验收：随机抽 5 个文件名核对存在性、数清单行数是否等于文件总数、看「待定」列表里有没有明显该归类的。
4. 把这次的任务描述存成模板——下一个练习换材料重跑，你该秒写。

**查一查**

查你所用工具的**日志或 trace 功能**：它在哪显示自己每一步干了什么。这次任务里故意看一遍完整轨迹，数它一共调了几次工具。

**验收**

清单与实际一致（抽 5 + 数总数都过），并且你能说出它一共走了几步。

**注意**

副本目录不是形式主义。「它顺手把文件删了」是新手损失最惨的事故，而防它的唯一可靠办法就是别让它在原件上第一次干活。

## Lv2-4 接一个只读 MCP

**场景**：Lv1 的练习里你只能手动贴资料。这次让 agent 自己够到外部。

**目标**：配置一个只读的网页抓取类 MCP，并验证它真的调用了而不是编。

**步骤**

1. 按你所用工具的官方文档，配置一个 fetch 类 MCP。**配置前先做下一步。**
2. 查一查里的核实动作先做完，再动手配置。
3. 配置后重启客户端。
4. 问一个必须联网才能答的问题（比如某开源项目当前的最新版本号）。
5. 看它的轨迹：是**真的调用了工具拿到结果**，还是凭训练数据答的——这两者的区别你在 Lv1-2 已经见过了。

**查一查**

这是全套练习里最重要的一次查证：**教程和你手上任何文档里写的 MCP 包名，可能与官方仓库不一致**。打开该 MCP 的官方仓库 README，逐字核对包名和配置参数。把差异记下来——这个仓库的 `mcp-setup.md` 里就留了一次真实的包名修正记录，你可以对一下你查到的和它写的一致不一致。

**验收**

一次真实的工具调用记录（在轨迹里能看到），加上一条你对包名核实的结论。

**注意**

只接**只读**的。写操作类 MCP（能改文件、能发消息的）留到 Lv3 以后，且必须配人工确认——这条在教程 06 坑 5 里展开过。

# 01 · 什么是 Agent

先别急着看定义。我给你一个场景，你自己判断这里面「谁是 Agent」。

我让 AI 帮我查一下明天上海要不要带伞。它回我一句「明天上海有雨，记得带伞」。这是聊天机器人。

我又说：「帮我把这句话整理成一条待办，加到我的清单里，弄完告诉我。」它自己打开了我的清单文件、写进去、回我一句「加好了」。这是 Agent。

差别不在它多聪明，而在于**它有没有自己动手去做事**。前者只输出文字，后者会为了一个目标，自己去调用工具、改东西、然后检查结果。

## 一句话定义

> Agent 是一个**循环**：语言模型挑一个工具、执行它、读回结果、再决定下一步，如此往复，直到它认为任务完成。

这句定义我抄得理直气壮，因为它几乎是所有资料的共识。Amanai Lab 那篇说得更直白——「agent 就是个循环，复杂度全来自怎么让这个循环可靠」。这句话我建议你记下来，整套教程后面都在讲「怎么让它可靠」。

注意这里有两层意思，新手常常只看懂第一层：

1. **它会动手**（调用工具、读写文件、访问网络）
2. **它会自己决定下一步**（不是你把步骤写死，而是它在循环里自己判断）

第二层才是关键。如果你把每一步都写死了，那就不是 Agent，是脚本。

## 和另外两个东西划清界限

这三个词新手最容易混，我列个表给你钉死：

| | 聊天机器人 | 自动化脚本 | Agent |
|---|---|---|---|
| 谁决定下一步 | 没有下一步 | 你写死的 | 模型自己判断 |
| 会不会动手 | 不会，只说话 | 会，但只按固定路线 | 会，路线自己定 |
| 换一种情况会怎样 | 还能聊 | 大概率直接崩 | 多半能自己调整 |
| 典型例子 | 问答窗口 | 每天定时备份文件 | 「找出项目里所有没写测试的函数并补上」 |

有个说法我特别喜欢，来自 AI Discoveries 那篇：**没有记忆的 agent 不是 agent，是一台昂贵的聊天机器人**。这句话有点狠，但它点到了一个真问题——很多人做出来的「agent」，其实只是一次性调用，做完就忘，那确实跟聊天机器人没本质区别。

## 「自主」到底有多自主

这是我最想跟你掰扯清楚的一点，因为新手容易走两个极端：要么把 Agent 当神仙，要么觉得它一无是处。

真相是：**它的自主性完全来自你给的边界。** 它能碰什么工具、能改哪些文件、什么时候必须停下来问你，这些全是你定的。它不是自己想干什么就干什么，是在你划的圈里自己想路线。

举两个真实边界的例子：

- 只读的搜索、查资料，可以放它自己跑，错了也就是白跑一趟。
- 发邮件、付款、删数据这种不可逆的操作，几乎每一篇资料都建议：**必须停下来让人确认**。Zapier 那类文章还专门强调，这类动作在你有足够信心之前，一律加人工审批。

所以一个靠谱的 Agent，往往是这么长的：

```
能自己做的事：查资料、读代码、写草稿、跑测试
必须问人的事：删文件、发消息、动钱、改线上配置
```

## 三个你可能真的会遇到的小 Agent

别看概念了，看几个具体的。这几个都不复杂，你之后大概都会做。

**研究小助手。** 给它一个题目，它自己去搜、去读、最后整理成三个要点给你。TheAI 學院那篇的入门例子就是它。工具很少——一个搜索、一个读网页、一个输出。

**项目管家。** 它读你项目里的说明文件和历史踩坑记录，帮你改一个小 bug，改完跑一遍测试，再把这次的教训记下来。这就是本仓库 `my-first-agent` 在做的事。

**审核员。** 你写完一段代码，让它按固定的几轮标准挑毛病：需求对不对、边界情况漏没漏、有没有安全问题。这个不是「会写代码」，而是「会挑刺」，反而更适合新手交给 agent 去做。

## 几个我想提前打破的误解

**「用了大模型就自动是 Agent 了。」** 不是。你得给它工具，得写循环，得让它能读到结果。光调一次 API 拿一段文字，那还是聊天机器人。

**「Agent 必须很复杂。」** 恰恰相反。我翻的所有资料里，唯一从头到尾没变过的一句话是：**从最简单能用的版本开始**。你会写七步流程不代表你的第一个 agent 就要七步。三步能跑通，就先用三步。

**「框架装好就万事大吉。」** 框架能省你重复劳动，但那个核心循环本身简单到可以用任何语言手写。第 08 章会专门聊这件事，那儿有个真实的分歧。

**「它跑起来我就能不管了。」** 反了。你越是不看它，越容易出事——无限循环烧钱、悄悄失败、改了不该改的东西。第 06 章一整章都在讲这个。

## 这一章你要带走的一句话

> Agent = 会自己挑工具、执行、看结果、再决定的循环。它有多自主，取决于你给的边界。

---

**动手：** 打开你平时用的任意一个能对话的 AI，问它一个问题。然后再问一次，这次加上一句「如果这一步需要查资料或者改文件，你自己想办法做完再告诉我」。感受一下「只回答」和「去做」的差别——这就是这一章全部的内容。

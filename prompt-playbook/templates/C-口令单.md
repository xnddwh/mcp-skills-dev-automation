# C 型 · 口令单

> **用途**：已经写成 skill 的流程，一句话触发。

## 模板

```
<口令> <参数>
```

## 建口令的时机（教程判据）

**同一件事做过 3 次以上** → 立刻固化成 skill + 口令。

流程：
1. 写 skill（`SKILL.md`，含 name / description / 步骤 / 验收）。
2. 定口令（短、可区分、不撞车）。
3. 登记进 `口令表.md`。
4. 测试：开新会话，只用口令触发一次，看它是否自动按步骤走。

## 规范要点

- **口令必须对应真实存在的 skill / 文件**，否则是空口令。
- description 决定触发时机，**写得含糊就永远不会被触发**（教程原话）。
- 参数化：把每次会变的东西做参数，固定的写死在 skill 里。

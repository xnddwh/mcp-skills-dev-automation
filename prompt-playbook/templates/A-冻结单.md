# A 型 · 冻结单

> **用途**：任何需要动手改东西的**首次任务**。最核心的一类。
> **心法来源**：教程「阶段二 · 任务三件套」，本模板在其基础上增加"禁止"与"不确定的点"。

## 模板（复制这一块）

```
【任务冻结】
目标：<一句话，可验收>
背景：<我是谁 / 这是什么项目 / 关键约束>
允许改：<文件或目录清单>
禁止：<git / 删文件 / 装依赖 / 改接口 / 其他>
验收：<可执行判据，如 "run_tests.py 全绿" 或 "清单行数=文件数">
不确定的点：<列出，先只回答这些，别动手>
```

## 填单规范

- **目标**必须一句话说得清，写得清才做得对。
- **验收**必须能打勾：要么是可跑的命令，要么是可数的数字。
- **禁止**永远要写。你不写，它就敢删。
- **"不确定的点"放最后一行** —— 强制 AI 先问答疑点，你批准后才动手。
- 填不出"不确定的点"，说明你自己还没想清，先想再问。

## 反例 → 正例

✗ **差的写法**
```
帮我整理一下这个文件夹。
```

✓ **好的写法**
```
【任务冻结】
目标：把下载文件夹里的 PDF 按年份分类，生成 index.md
背景：约 200 个 PDF，论文和发票混在一起
允许改：仅新建 index.md 和分类子目录
禁止：删除、重命名、移动任何原文件
验收：index.md 行数 = PDF 总数；随机抽 5 个文件名可核对
不确定的点：发票没有年份怎么归类？先回答再动手
```

## 用完就收

任务结束后，若同类还会再做 → 立刻沉淀为 **B 型 · 例行单**。

# B 型 · 例行单

> **用途**：每周/每天重复做的事。**由 A 型沉淀而来。**

## 模板（复制这一块）

```
【<任务名> · 例行】
按 <上一次的模板 / 流程文件> 执行本周 <任务>。
本次输入：<本周的新数据 / 变更>
差异点：<与上次不同的地方，没有就写"无">
照旧验收：<上一版的验收标准>
```

## 沉淀动作（关键）

第一次用 A 型做完后，**立刻**把这份 A 型存成 B 型模板：

1. 起个名（如 `B-周报`、`B-行业新闻整理`）。
2. 把固定的部分保留，把变化的部分挖空成 `<本次输入>`。
3. 存进 `prompt-playbook/templates/`。
4. 下次只说"按上次流程做"，附本次差异。

## 规范要点

- **差异点必须显式写**，哪怕写"无"。不写它就会照抄上次，忽略这次的不同。
- 验收标准沿用上一版；**要改验收标准，就重写一份 A 型**。
- 例行单不写"禁止"——禁止项已在流程文件里，此处不重复。

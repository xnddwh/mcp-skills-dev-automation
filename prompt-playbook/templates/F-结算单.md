# F 型 · 结算单

> **用途**：周期收尾（周/月/项目阶段末），产出下一周期唯一首选。

## 模板（复制这一块）

```
【结算 · <周期>】
已完成：<逐项列，标证据等级>
未完成：<原因，是否阻塞>
数据：<关键指标：通过数 / 耗时 / 成本>
教训：<本次返工点 → 防复发规则>
下一周期唯一首选：<一件事>
```

## 规范要点

- **用数据说话**，不用"感觉不错"。给不出数据就写"无数据"，别编。
- **教训必须落到回流动作**（写进台账或 skill），否则结算白做。
- **只给一个下一周期首选** —— 不给菜单，不让你选。

## 证据等级标记（可选）

| 标记 | 含义 |
|---|---|
| 【实证】 | 亲手验证过 |
| 【数据】 | 有数字支撑 |
| 【官方】 | 来自权威文档 |
| 【推算】 | 由已知推得 |
| 【自述】 | 你自己说的，未核 |

## 三个体检动作（配套使用）

- **抽检**：本周 5 条提示词，有没有验收 / 禁止 / 可复用？
- **台账转化率**：台账 N 条 → 几条变规则？< 50% = 台账在当抱怨清单。
- **闭卷自测**：不看资料能否写出 A 型五字段？

# 最小错误台账（Mistakes Ledger · 3 字段版）

> **每次返工，当场加一条。** 3 字段版是日常用的轻量版；重要错误再补全 6 字段（见文末）。
> 核心原则：**每条错误都要变成一条明天的规矩**，否则台账只是抱怨清单。

## 追加模板

```
### YYYY-MM-DD  <一句话标题>
- 错在哪：<具体>
- 下次怎么防：<一条能明天用上的规则>     ← 最重要
- 怎么验证：<可执行判据>
```

## 已登记

### 2026-10-11  教训只写在提交信息里、没进 skill
- 错在哪：核对 skill 落盘条目时发现"重试走安全档"只写在 commit message，skill 正文里没有
- 下次怎么防：会话收尾时逐条核对"提交信息提到的结论是否都在 skill 里"
- 怎么验证：`grep -c "重试走安全档" SKILL.md` ≥ 1

### 2026-10-11  报"缺内容"前没跨模块检索（两次误报）
- 错在哪：判定"抽样定理 / 各态历经性"缺卡，实则内容都在
- 下次怎么防：报缺卡/缺内容前必须先按大纲条跨模块 `grep -rl`
- 怎么验证：给出的每条"缺失"结论都能附上全库检索命令与结果
